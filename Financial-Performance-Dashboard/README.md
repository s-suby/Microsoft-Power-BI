# Financial Performance Dashboard

## Overview

This Power BI dashboard provides an executive view of financial performance across revenue, profitability, expenses, cash flow, business units and regions.

The report is designed to give a concise summary of key financial metrics with interactive filtering and year-over-year comparison.

## Key KPIs

* Total Revenue
* Gross Profit
* Net Profit
* Profit Margin
* Total Expenses
* Operating Cash Flow

## Dashboard Features

* Current year vs previous year revenue trend
* Monthly profit performance
* Revenue by business unit
* Revenue by region
* Monthly profit margin analysis
* Dynamic YoY KPI indicators
* Date, business unit and region filters

## Tools Used

* Microsoft Power BI
* DAX
* Power Query
* CSV

## Project Structure

* `data/` — Source dataset
* `dax/` — DAX measures used in the report
* `pbix/` — Power BI report file
* `screenshots/` — Dashboard screenshots
