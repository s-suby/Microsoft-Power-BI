# Retail Banking Performance Dashboard

## Overview

This project presents a Power BI dashboard designed to provide an executive-level view of retail banking performance.

The dashboard tracks key metrics including transaction value, active customers, active accounts, new customers, accounts opened, average transaction value, customer segments, transaction channels, and high-value transactions.

## Business Objective

The goal of this dashboard is to help stakeholders quickly understand overall banking performance, identify trends, compare current performance against the previous year, and highlight areas that may require further investigation.

## Key KPIs

- Total Transaction Value
- Active Customers
- Active Accounts
- New Customers
- Accounts Opened
- Average Transaction Value
- Year-on-Year Growth
- Month-on-Month Growth

## Dashboard Features

- Executive KPI overview
- Transaction value trends
- Customer segmentation analysis
- Growth trend analysis
- Account status performance
- Transaction channel analysis
- Top 10 high-value transactions
- Interactive filters for date, region, customer segment, and account type

## Business Value

The dashboard enables business stakeholders to monitor performance from a single view, identify changes in customer and transaction activity, compare performance over time, and investigate the key drivers behind banking performance.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Modelling
